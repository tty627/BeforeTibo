Formats and limits

UTF-8, optional BOM, comma-separated, quoted fields, escaped quotes and multiline fields are supported. Both files must have the same unique, nonempty column names. Keys must be unique and nonempty. Values remain strings: 001 differs from 1, and spaces are preserved. Results are sorted by the key's code-unit order.

Each input is limited to 5 MiB or 20,000 data rows. The preview shows up to 500 rows per category; JSON export retains every difference. Files with different columns, duplicate keys, malformed quotes or invalid UTF-8 are rejected.
